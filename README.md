# استهلاك نوفا

برنامج بسيط لتسجيل الاستهلاك اليومي وإخراج تقارير PDF وكشف حساب. يشتغل من المتصفح، ويتثبّت على الموبايل كأنه تطبيق، ويشتغل بدون إنترنت.

## الملفات
- `index.html` — البرنامج كله
- `manifest.json` و `sw.js` — علشان يتثبّت ويشتغل بدون نت
- `icon-192.png` و `icon-512.png` و `icon-maskable-512.png` — أيقونات التطبيق
- `lock.jpg` — صورة شاشة القفل
- `logo-t.png` — الشعار (يظهر كخلفية خفيفة لو فعّلتها)

## رفعه على GitHub Pages (من الموبايل أو الكمبيوتر)
1. ادخل على github.com وسجّل دخول (أو اعمل حساب مجاني).
2. اضغط **New repository**، واكتب أي اسم بالإنجليزي مثل `esthlaky`، واختار **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، واختار الملفات التسعة كلها (بما فيها `README.md`)، ثم **Commit changes**.
   - لازم الملفات تكون في الصفحة الرئيسية للمشروع، مش جوه مجلد.
4. ادخل **Settings** ← **Pages**.
5. في **Branch** اختار `main` وبجانبها `/ (root)`، ثم **Save**.
6. استنى دقيقة أو اتنين، وهيظهر رابط البرنامج: `https://اسم-حسابك.github.io/esthlaky/`

## تثبيته على الموبايل
افتح الرابط في **Chrome**، ثم قائمة ⋮ ← **تثبيت التطبيق** (أو **إضافة إلى الشاشة الرئيسية**).

## نقل بياناتك القديمة
البيانات بتتخزن على الجهاز نفسه حسب الرابط، فالرابط الجديد بيبدأ فاضي.
1. في البرنامج القديم: **الإعدادات** ← **نسخ النسخة الاحتياطية** (أو **تنزيل نسخة احتياطية**).
2. في البرنامج الجديد: **الإعدادات** ← الصق النص أو اختار الملف ← **استعادة**.

خد نسخة احتياطية بشكل دوري، لأن مسح بيانات المتصفح بيمسح السجل.

## ملاحظات
- الصوت بيشتغل على Chrome في أندرويد، ومحدود على iPhone.
- لو غيّرت `index.html` وعايز التحديث يظهر، افتح البرنامج وانت متصل بالإنترنت (بيتحدّث تلقائيًا). ولو غيّرت أي ملف تاني غير `index.html`، غيّر رقم النسخة في أول `sw.js` (`esthlaky-v2` ← `v3`).
- المشروع على GitHub Pages المجاني بيكون عام. الكود ظاهر لأي حد معاه الرابط، لكن بياناتك لا.
